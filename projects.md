# Projects and case studies

## Find the Tempo

**Type:** Web app · Next.js

Turns a screenshot of a song list into links you can play. OCR reads each track and artist, then builds one search link per streaming service, with no paid APIs.

[Full case study](design-find-the-tempo.md) · [Live site](https://findthetempo.netlify.app)

## Nidhi

**Type:** Prototype · JavaScript

An unofficial redesign of EPFO member access. One sign-in for passbook, claims and profile, clearer sign-in errors, and password rules shown before a reset. All data is made up.

[Live site](https://nidhi-epfo-portal.kaey-codes.chatgpt.site/#login)

## OpenBoard

**Type:** Local app · React

A moodboard that runs on your own computer. Your images stay as plain files in a folder you choose, and OpenBoard adds tags, folders, notes, a free canvas and a mind map.

[Repository](https://github.com/kaushikhegde11/OpenBoard)

## Claude Code statusline

**Type:** CLI tool

Shows your Claude plan usage in the Claude Code status line: the 5-hour session and the 7-day week as colored bars, plus which day of the weekly window you are on.

[Repository](https://github.com/kaushikhegde11/claude-code-weekly-statusline)

## Strudel skill

**Type:** Assistant skill

Teaches beginners to write, explain and fix Strudel live-coding music patterns, with no music theory or JavaScript needed. One source works in Claude Code, Codex CLI and ChatGPT.

[Repository](https://github.com/kaushikhegde11/strudel)

## Airbnb: the anxious gap

**Type:** UX case study

A solo study of the time between booking and check-in. A heuristic review and small guerrilla tests found five problems across Search and Trips, with a fix for each.

[Full case study](case-study-airbnb.md)

## Obsidian project memory

**Type:** Assistant skill

Gives each project a small memory in an Obsidian vault: an overview, current status, a dated log and a decision record. An assistant reads it to pick up where you left off.

[Repository](https://github.com/kaushikhegde11/obsidian-project-memory)
