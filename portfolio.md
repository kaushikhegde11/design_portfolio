## Projects and case studies

### Find the Tempo

A web app that turns a screenshot of songs into openable streaming links. OCR reads each track and artist, then builds one search link per streaming service.

[Full case study](design-find-the-tempo.md) · [Live app](https://findthetempo.netlify.app) · [Repository](https://github.com/kaushikhegde11/find_the_tempo)

### Airbnb: the anxious gap

A solo case study of the period after booking and before check-in. It examines Search tab persistence and the hierarchy of booked-trip information through a heuristic review and small-sample guerrilla usability sessions.

[Full case study](case-study-airbnb.md)

### Strudel skill

**What it is:** Beginner-friendly assistant instructions for Strudel live-coding music - teaches writing, explaining, and debugging patterns from zero music-theory or JS knowledge.

**Built for:** Claude Code, Codex CLI, and ChatGPT, from one shared source.

[View repo on GitHub ↗](https://github.com/kaushikhegde11/strudel)

### Nidhi

**What it is:** An unofficial design prototype rethinking EPFO member account access - one sign-in across core services, clearer errors, better password guidance.

**Built for:** Browser-based, no backend. All data is synthetic; nothing is sent anywhere.

[View repo on GitHub ↗](https://github.com/kaushikhegde11/nidhi-epfo-portal)

### Weekly statusline

**What it is:** A Claude Code statusline showing session and weekly rate-limit usage as colored bars, plus a day counter for the 7-day window.

**Built for:** Claude Code, as a drop-in statusline script.

[View repo on GitHub ↗](https://github.com/kaushikhegde11/claude-code-weekly-statusline)

### Obsidian project memory

**What it is:** Gives each project a small, durable memory inside an Obsidian vault - a README/STATUS/progress/Decision system an assistant reads later to recover context fast.

**Built for:** Claude Code and Codex CLI, as skills; any file-reading agent can use the same source.

[View repo on GitHub ↗](https://github.com/kaushikhegde11/obsidian-project-memory)
